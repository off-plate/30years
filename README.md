# 30 let — Akcie vs. vlastní byt

Dlouhodobá finanční kalkulačka pro český trh. Modeluje 1–30 let s inflací, růstem nájmu, refixací hypotéky, údržbou bytu a daňovým pohledem.

## Lokální spuštění

```bash
npm install
npm run dev
```

## Deploy na GitHub Pages

```bash
npm run deploy
```

Web bude na: https://off-plate.github.io/30years/

## Defaultní hodnoty (ČR 2026)

- Inflace: 2,5 %
- Výnos akcií (MSCI World v CZK): 7,5 %
- Růst nájmu: 4 %
- Zhodnocení nemovitosti (Praha): 5 %
- Sazba hypotéky: 5,2 %
- Údržba bytu: 1 % z hodnoty / rok
